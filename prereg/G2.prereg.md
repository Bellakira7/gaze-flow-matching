## 1. 比较对象

- **我方法**：冻结 backbone + 生成式 gaze decoder，输出 K 个带权重假设与样本（计划 §4）。超参、训练轮数、从样本到假设的聚类方式等一切选择，**只能用 GazeFollow 训练集的 hold-out 切片**决定；测试集只在最终读数时使用一次。
- **baseline（计划 §5.1，同一冻结 backbone、同一训练数据、同一增强与训练预算）**：
  - B1 Gaze-LLE 风格热图头，假设 = NMS 前 5 个峰（S1 定义），pmf = 热图（raw 与 S1 的 cf 两种）；
  - B2 同一网络的热图采样（从 pmf 独立抽样）；
  - B3 MDN（混合高斯）；
  - B4 MCL / winner-take-all（K=5 个头）；
  - B5 热图 diffusion。
  - B3–B5 的假设与样本按各自原生输出，缺少的字段用与我方法**相同**的后处理管线补齐。
- **“最强 baseline”**：对每个指标、每个子集，取 B1–B5 中该指标最好者。B1–B5 全部实现并读数才能判定 G2；少任何一个，G2 记为 INCOMPLETE，不判 PASS/FAIL。
- **官方 Gaze-LLE ViT-L（DINOv2）**的 S1 数字只作参照。**最终 ViT-L 模型**的比较中，最强 baseline 额外把它纳入（取更强者）；11/04 的 G2 用同 backbone（快速迭代用的 ViT-B）的重训 baseline。

## 2. 方法输出规范

每个测试实例必须给出（顺序与 `results/setmetrics/s1_per_instance.npz` 的实例顺序一致）：
- `hyps [5,2]`、`w [5]`：恰好 K=5 个假设与权重（≥0，和为 1，降序）。
- `samples [10000,2]`：10000 个样本，坐标在 [0,1]²。可选 `pmf [64,64]`：精确 pmf，仅用于报告精确 NLL，不参与判定。
- **点估计** = `hyps[0]`（权重最大的假设），不允许另设规则。
- **热图（算 AUC）** = 由样本得到的 pmf（§3.2）除以其最大值，按官方方式双线性放大到原图尺寸。
- 所有模型（B1–B5 与我方法）的 pmf 一律由 10000 个样本经 §3.2 管线生成；有原生 pmf 的模型（B1/B2 热图、B3 MDN 的混合密度）用其 pmf 抽样后进入同一管线。

## 3. 指标与阈值

### 3.1 主指标 P1：覆盖（越高越好）

`cov0.10@5`：被 5 个假设中某个覆盖（距离 ≤ 0.10）的标注者占比，逐实例再取子集均值（S1 定义）。
改进量用**漏检率相对下降**：`Δ1 = (cov_method − cov_base) / (1 − cov_base)`。**阈值：Δ1 ≥ 10%**。

用官方 Gaze-LLE ViT-L 的 S1 数字做参照：全体 cov_base = 0.852125（需 cov ≥ 0.8669）；M_sep cov_base = 0.743701（需 cov ≥ 0.7693）。

### 3.2 主指标 P2：NLL（越低越好）

**同一条管线，对所有模型对称**：每个模型给出 10000 个样本；按格计数，做高斯平滑（σ_s ∈ {0.5, 1, 1.5, 2, 3, 4} 格），与均匀以 λ=1e-3 混合得到 pmf；σ_s 用 S1 同一个 2 折（`np.random.default_rng(0).permutation(帧号)` 的后半为折 1）交叉拟合选择（用另一折的平均 NLL 最小者）。有原生 pmf 的模型用其 pmf 抽 10000 个样本进入同一管线，因此有限样本估计误差对所有模型相同。baseline 在其可用的 pmf 变体中**取子集平均 NLL 最低者**（B1/B2：raw γ=1 与 cf 两种；B3–B5：各自一种），因此对 baseline 略有利。精确 pmf 的 NLL（S1 口径）照报，不参与判定。

NLL 定义同 S1（nats / 标注点）。**阈值**：`NLL_base − NLL_method ≥ max(0.10 × (NLL_base − NLL_ref), 0.01)`，其中 `NLL_ref` 为 S1 的 LOO-KDE 参照：全体 5.437658，M_sep 5.872344（固定常数）。

用官方 Gaze-LLE ViT-L 在本管线下的数字做参照（`results/setmetrics/official_gazelle_vitl_bundle_v2.npz`；样本管线 NLL，raw 与 cf 取更低者，两个子集都是 raw）：全体 NLL_base = 5.774448，阈值 0.0337（需 NLL ≤ 5.7408）；M_sep NLL_base = 6.470558，阈值 0.0598（需 NLL ≤ 6.4107）。精确 pmf 口径下它们是 5.730203 / 6.424095，仅供对照。

### 3.3 约束 C：标准指标不劣化（全体，对同 backbone 的 B1）

用 S1 的修正 argmax 口径（格子中心）：`AUC_method ≥ AUC_B1 − 0.005`；`AvgL2_method ≤ AvgL2_B1 + 0.005`；`MinL2_method ≤ MinL2_B1 + 0.005`。（对计划里“波动不超过 ±0.005”的解读：不劣化超过 0.005；变好不算违约。）

## 4. 统计

对帧做 cluster bootstrap（B=2000，seed 0，与 S1 同一套重采样），对**配对**改进量给 95% 区间。

## 5. 判定

- **PASS** 当且仅当同时满足：
  - **A（全体）**：P1 的 Δ1 ≥ 10% 且 P2 达阈值，**两者点估计达标，且改进量的 95% 区间下界 > 0**；
  - **B（M_sep）**：P1、P2 点估计均达阈值（M_sep 仅 291 个实例，功效低，不设区间条件，区间照报）；
  - **C**：标准指标不劣化。
- **FAIL**：B1–B5 全部读数且 PASS 条件不全满足。
- **INCOMPLETE**：缺任一 baseline 或任一必需字段。
- 后果沿用计划：PASS → 冲 CVPR（最终是否冲仍由用户决定）；FAIL → 直接做 ICCV。

## 6. 防作弊约束

1. K 固定为 5，样本数固定为 10000；权重和为 1；pmf 必须在 [0,1]² 上归一化并含 λ 混合。
2. 方法与 baseline 同一冻结 backbone、同一训练数据、同一增强与训练预算；调参只用训练 hold-out。
3. 测试集标注只用于 σ_s 的 2 折交叉拟合（baseline 的 γ 同样如此），不得用于任何其它选择。
4. 不得对测试集反复读数后再改规则；读数只做一次，之后的修改按 §8 记为偏离。
5. 点估计固定为 `hyps[0]`；不允许为标准指标另设解码规则。

## 7. 非判定项（照报）
