## C4 B3/B4/我方法的训练与调参流程（读数前固定）

## C5 B5（热图扩散）的定义与调参（2026-10-22 追加；读数前，未读过任何 B3/B4/B5/我方法 数字）

- **生成对象**：官方训练目标热图 `get_heatmap(gx, gy, 64, 64)`（σ=3 格高斯，峰值 1），映射到 [-1,1]。**去噪网络**：64×64 噪声热图 2×2 patchify 成 32×32 token，加场景 token（与 B3/B4/我方法共用同一个 Trunk）与位置编码，3 个带时间 FiLM(adaLN-zero) 的自注意力 Block，输出 v；v-prediction、余弦调度、连续 t；DDIM(η=0)，x0 截到 [-1,1]；去噪网络采样时 bf16（实测与 fp32 混合 pmf 的 TV=0.005，低于采样噪声 0.03–0.05）。代码 `gazelle_online/gaze_diffusion.py`。
- **原生输出**：每实例画 M_draw 张热图，各自截 0 并归一化后取平均 = 原生 pmf（与 B1 的"一张确定热图"相比，差别只在热图是回归的还是扩散后验样本的混合）；点样本 = 从该 pmf 抽（格内均匀抖动）；假设 = 该 pmf 上 NMS 前 5 峰（半径 0.1，权重 = 峰周围半径 0.1 圆盘质量，与 B1 同定义）；10000 样本再走 §3.2 同一条管线。
- **预声明的调参**：训练 lr 同 C4（{1e-3, 3e-4} 的 3-epoch 筛选，按 hold-out nll_best）。**采样步数 ∈ {16, 32, 64}** 在训练 hold-out（3762）上用最终 ckpt 选，选 nll_best 最低者；**M_draw 固定为 64**（受算力限制，不调；M_draw=16 与 64 在 hold-out 上的差别作为非判定项照报）。训练中每 epoch 的 hold-out 监控用 M_draw=16、16 步（仅用于 lr 筛选和曲线，不用于选步数）。
- **为什么步数要调（读数前的发现）**：合成双峰上，16 步 DDIM 的模式权重偏差 7.5 个百分点（1024 张采样选 A 占 0.675，真值 0.6），64 步下偏差明显下降；模式内散布在 16 步下已正确。所以 B5 不能用默认 16 步，否则会人为削弱 baseline。
- **已知的对 B5 不利之处（报告时写明）**：原生 pmf 由有限张热图混合而成，M_draw=64 时 pmf 噪声高于 B1/B2/B3 的解析 pmf；这是扩散热图作为 baseline 的固有代价，不是实现缺陷，但读数时要与 M_draw 敏感性一起给出。

- 两种口径下 baseline 集合都是 {B1–B5（各自该口径）} ∪ {官方 Gaze-LLE ViT-L（同口径：gt 用 `official_gazelle_vitl_bundle_v2.npz`，eye 用 `results/g2/bundle_B1_official_eyebox.npz`）}；约束 C 对同口径的 B1。
- 每个臂（B1–B5、我方法）需要各跑两次测试集预测（gt 与 eye）。除头框外其余一切（权重、采样种子、聚类、σ_s 交叉拟合）相同。**这是同一个 ckpt 的两次输入口径，不算对测试集反复读数后改规则**；但不得因为一种口径下结果更好就改变判定口径。

## C21 集合原生混合 flow 头（mixflow）：设计、固定配置、hold-out 选择规则与测试集读数（2026-11-02 追加；写于任何 mixflow 的真实数据训练 / hold-out / 测试数字之前）

- **背景**：用户 11-02 决定主方法 = flowET_d6（C18）并继续找方法创新，选定「set-native mixture-of-flows」。这是第六个事后追加的方法，不改 C10–C18 的任何判定。**须披露**：方向选择依据的全部是已看过的数字（MCL 覆盖最高 / flow NLL 最好 / d6+fuse 等权混合 hold-out NLL −0.050 / M_sep 密度头过度自信且 T=1 已最优），其中 M_sep 的部分来自已读的测试集。截至本条写入，mixflow 只跑过**合成**自检（`test_gaze_mixflow.py`），没有任何真实数据数字。
- **设计**（`gazelle_online/gaze_mixflow.py`）：p(y|x)=Σ_k π_k(x)·p_k(y|x,e_k)。K 个可学 query 经 2 层交叉注意力 gate 解码出锚点 a_k（sigmoid）、π logit、成分 embedding e_k；flow 分支与 FlowHead 同构（depth=4、FiLM、末层零初始化），条件 = t 嵌入 + comp(e_k, Fourier(a_k))，锚点作条件时 detach（锚点只由 WTA 训练）。训练 = relaxed hard-EM：赢家 k*=argmin_k‖a_k−y‖，w=(1−ε) 给赢家、ε/(K−1) 给其余；loss = Σ_k w_k·FM_k + λ_a·WTA + λ_π·CE(π,w)。采样：k~π 后按成分条件走 ODE（与 FlowHead 同款 Heun/时间网格）。**原生假设** = predict()：锚点按固定半径 0.10（= 评测协议的假设匹配半径，不是调出来的超参）确定性合并——权重求和、π 加权质心——按权重降序；点估计 = 权重最大的合并假设。合成自检依据：K>峰数时重复锚点的 π 按峰求和恰恢复真实峰权重（0.602/0.398 vs 0.6/0.4），合并因此是口径修正而非调参。
- **容量**：头 6.278M，对比较对象 flow_eye_d6_s0 的头 6.462M 差 −2.84%（略小，偏保守）。
- **固定配置（不在 hold-out 上调）**：K=5、gate 2 层、flow depth=4、ε=0.05、λ_a=1.0、λ_π=0.1、n_draw=16/成分、merge=0.10；带眼部 token（EyeGazeModel，crop 224 / margin 1.25，与 flowET 相同）；训练配方与 flowET/flowET_d6 相同：4 卡、全局 batch 64、lr 3e-4、cosine、clip 5、15 epoch、seed 0，取 `epoch_14.pt`；推理采样器与 σ_h 读 `sampler_selection.json`（Heun/16/γ=3；σ_h=1 只用于"样本聚类口径"的对照列，原生口径不用 σ_h）。
- **hold-out 选择规则（读测试集之前做出）**：主比较 = `mixflow_eye_s0` 对 `flow_eye_d6_s0`（容量对齐、当前主方法 C18），10000 样本逐实例配对、bootstrap B=2000（与 C16/C17 同口径）；**NLL 低 ≥0.02 才算胜出**。同时照报：对 `flowET_s0_rayeval` 的差；该臂自己的两套假设口径（原生 merge 后 vs 样本聚类 σ_h=1）的 cov10/cov05/点 L2。
- **机制判据（hold-out，支撑"假设集可原生输出、不需要事后聚类"这句话）**：原生口径对同臂样本聚类口径的配对差满足 点 L2 差的 CI 上界 < +0.005 且 cov10@5 差的 CI 下界 > −0.01；不满足则论文不得写"原生假设可替代聚类"，只能报数字。
- **测试集读数**：`mixflow_eye_s0` 在 gt/eye 各读**一次**（方法名 `mixflowET`，假设用原生口径——与 B4 MCL 的"原生假设"同等待遇，S1 §3.2 允许；10000 样本概率图照常算 NLL/W1/AUC），无论 hold-out 结果如何都读、都报；G2 门槛照算照报，不得写成 G2 通过；M_sep 的 disc-ECE 与 Cov@5 在同一次读数里一并报（作机制验证，不作任何选择依据）。**仅当 hold-out 胜出**才训 seed 1 并各读一次（只作 seed 方差，不替换 s0、不取平均）。
- 评测工具需扩展（`eval_ray_holdout.py` / `predict_test_ray.py` 加 mixflow 口径），扩展只改口径支持、不改任何已冻结的 g2_eval/metrics 代码。
