## 1. 定义

坐标一律用归一化坐标（x/宽、y/高），距离为欧氏距离。实例 = 一个头；其标注集 A = 该头的全部标注者点（n 个）。

**簇与多峰**：`sklearn.cluster.DBSCAN(eps, min_samples=m)`，标签 -1 的点（噪声）忽略，其余每个标签为一个 mode。
- **多峰（multimodal）**：mode 数 ≥ 2。
- **分离良好的多峰（M_sep）**：多峰，且人数最多的两个 mode 的质心距离 ≥ 0.15（并列时取标签小者）。
- **主设定**：eps = 0.075，m = 3。
- **敏感性网格**：eps ∈ {0.05, 0.075, 0.10} × m ∈ {2, 3}。另报 m = 1 的数字，仅作上界参考，**不参与任何结论**。

**标注均值到最近标注点的距离** `d_mean`：‖mean(A) − a_i‖ 在 i 上取最小。

## 2. G1a：多峰比例（主设定上判定）

- 通过：多峰占全部 4782 实例的比例 ≥ 10%。
- 边缘：[7%, 10%)，交给用户裁决。
- 不通过：< 7%。
- 若敏感性网格里 m ≥ 2 的 6 个格子既有 < 7% 又有 ≥ 10%，标注为“定义敏感”，同样交给用户裁决。

另报（描述性，不判定）：`d_mean` 的分位数（总体 / 多峰 / 单峰）、`d_mean > 0.05` 与 `> 0.10` 的占比；按标注数 n 分桶的多峰比例。

## 3. G1b：中点作弊演示（用真实模型热图，不泄漏 GT）

热图格 (r, c) 的中心坐标为 ((c+0.5)/64, (r+0.5)/64)。

**非 oracle 估计量**（只用模型热图 h）：
- `argmax`：热图最大格的中心（即“修正 +0.5”口径）。
- `mid2`：p1 = argmax；屏蔽中心与 p1 距离 < 0.10 的格子后，p2 = 剩余格的 argmax；若 h(p2) ≥ 0.3·h(p1) 则取 p1 与 p2 的中点，否则退回 p1。
- `centroid`：对 h ≥ 0.3·max(h) 的格子，以 h 为权重取质心。

**Oracle 参照**（用了 GT，仅作上界说明，不参与通过判定）：
- `o_mean`：标注均值（按官方定义 Avg L2 恒为 0）。
- `o_mid2`：最大的两个 GT mode 质心的中点；不足两个 mode 时取最大 mode 的质心，没有 mode 时取标注均值。

**逐实例指标**：
- `avg_l2` = ‖pred − mean(A)‖（官方定义）。
- `min_l2` = min_i ‖pred − a_i‖。
- `HR@r` = 落在 pred 半径 r 内的标注者占比，r ∈ {0.05, 0.10}。

**判定**：在主设定的 M_sep 子集上，对帧做 cluster bootstrap（按帧重采样，2000 次，seed 0）。若存在非 oracle 估计量 E ∈ {mid2, centroid}，同时满足：
1. mean(avg_l2[E] − avg_l2[argmax]) 的 95% 区间上界 < 0；
2. mean(HR@0.05[E] − HR@0.05[argmax]) 的 95% 区间上界 < 0；

则 G1b 通过（含义：往中间猜让 Avg L2 更好，却让更少的标注者被命中）。否则不通过，如实报告。若 |M_sep| < 100，记为“样本不足”。

**描述性补充**（不判定）：
- Gaze-LLE 在单峰 / 多峰 / M_sep 上的 Avg L2、Min L2、AUC。
- M_sep 中预测热图出现第二峰（h(p2) ≥ 0.3·h(p1)）的占比。
- 热图 top-K 峰（用与 mid2 相同的屏蔽半径逐个取）对标注者的覆盖率：K = 1, 2, 3，半径 0.10。
